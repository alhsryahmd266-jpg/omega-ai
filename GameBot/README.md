# GameBot — بوت بيقرا الشاشة ويلعب على نفس الهاتف

تطبيق أندرويد مستقل (مش جزء من GVR-Chat). بيشتغل **كله على الهاتف** (مفيش صلاحية إنترنت أصلًا):
التقاط الشاشة ← كشف بنموذج TFLite ← قرار ← لمس حقيقي متعدد الأصابع.
مخصص **لاختبار لعبتك إنت** (QA / soak / load).

## الحقيقة من غير تجميل
- الـ APK بيتبني ويتنشر تلقائي من GitHub Actions، لكن **ما اتجرّبش على جهاز حقيقي** (الكود اتفحص compile بس). أول خطوة عندك: "اختبار حقن اللمس" جوّه التطبيق.
- **الوضع الذكي (AI)** محتاج نموذج كشف مدرّب على لعبتك. مفيش نموذج جاهز جوّه التطبيق عن قصد. بدونه التطبيق بيشتغل بوضع **Monkey** (حركة وتصويب وضرب عشوائي للاختبار).
- "أذكى من المحترفين" بيجي من جودة النموذج وبيانات التدريب، مش من التطبيق لوحده. التطبيق بيدّيك السرعة (قرار كل ~30 ملي ثانية) وخمس مستويات مهارة، والنموذج هو اللي بيحدد الذكاء.

## الإعداد (مرة واحدة)
1. **Shizuku** (مفضّل — لمس حقيقي متعدد): نزّل Shizuku، فعّل Developer options ← Wireless debugging، اعمل Pair من إشعار Shizuku، وشغّله. على أندرويد 12 غالبًا محتاج Wi‑Fi، وبيتعاد تشغيله بعد كل restart. بعدها اضغط "Shizuku" في GameBot ووافق.
2. **Accessibility** (بديل أبطأ + حماية): فعّل خدمة "GameBot Input".
3. **الظهور فوق التطبيقات**: عشان الـ HUD وزرار STOP.
4. **Usage access** (أو Accessibility): الحماية بتتأكد إن اللعبة هي اللي قدامك قبل أي لمسة.
5. استثناء من توفير البطارية.

## الاستخدام
1. اختار لعبتك.
2. **تعديل أماكن الأزرار**: التطبيق بيفتح اللعبة، ادخل ماتش، اضغط ⚙ Layout، واسحب كل دايرة (stick, look, fire, jump, crouch, reload, ads) فوق زرارها، واضغط حفظ.
3. **اختبار حقن اللمس**: لازم يقول "نجح" (لمستين في نفس الوقت على الأقل).
4. اختار الوضع والمستوى، واضغط **تشغيل**. التطبيق هيطلب إذن تسجيل الشاشة، وبعد تأخير البداية (5 ثواني) يبدأ.
5. **إيقاف**: زرار STOP في الـ HUD، أو من الإشعار، أو من التطبيق. وبيقف لوحده لو اللعبة خرجت من الشاشة دقيقة، أو الحرارة عالية جدًا، أو خلصت المدة القصوى.

## مستويات المهارة (للوضع الذكي)
| المستوى | زمن رد الفعل | سرعة التتبع | الضرب |
|---|---|---|---|
| Easy | 450ms | بطيء | رشقات قصيرة وهادية |
| Normal | 250ms | متوسط | رشقات + strafe |
| Pro | 120ms | سريع | رشقات أطول |
| Max | 0ms | أسرع ما يمكن | رشقات طويلة |

الحساسية: "حساسية التصويب" في الإعدادات (اضبطها على حساسية لعبتك). لو الكاميرا بتتأرجح قلّلها، لو بطيئة زوّدها.

## نموذج الكشف
شوف `training/README_AR.md`: تسجيل لقطات من التطبيق ← تصنيف (تلقائي من داخل لعبتك أو يدوي) ← تدريب على كمبيوتر ← تصدير TFLite ← استيراد في التطبيق ← "قياس سرعة النموذج".
الكلاسات: `enemy` (إجباري) و`enemy_head` (اختياري).

## ربط لعبتك (مهم للـ QA)
التطبيق بيبعت Broadcast للعبة وقت التشغيل والإيقاف عشان لعبتك تعرف إن اللي بيلعب بوت وتعلّم الجلسة (وبالتالي ما تبوّظش الإحصائيات):
- `com.ahmedxg.gamebot.action.BOT_STARTED` (extras: `mode`, `skill`)
- `com.ahmedxg.gamebot.action.BOT_STOPPED`

مثال (Kotlin) جوّه لعبتك:
```kotlin
val f = IntentFilter().apply { addAction("com.ahmedxg.gamebot.action.BOT_STARTED"); addAction("com.ahmedxg.gamebot.action.BOT_STOPPED") }
registerReceiver(object : BroadcastReceiver() {
    override fun onReceive(c: Context, i: Intent) { isBotSession = i.action.endsWith("BOT_STARTED") }
}, f, Context.RECEIVER_EXPORTED)   // على أندرويد أقدم من 13 استخدم registerReceiver(receiver, f)
```
استخدم حسابات اختبار مخصوصة للبوتات على السيرفر.

## استكشاف الأخطاء
| العرض | السبب/الحل |
|---|---|
| "مفيش وسيلة تحكم" | Shizuku مش شغّال أو مش ممنوح، ومفيش Accessibility. |
| اختبار الحقن "فشل" | جرّب backend تاني من القائمة، أو أعد تشغيل Shizuku. |
| اللمس بيروح مكان غلط | عدّل الـ layout، وتأكد إن اللعبة في نفس الاتجاه (landscape). |
| FPS واطي / سخونة | قلّل دقة الالتقاط (320)، قلّل الـ FPS، جرّب GPU/CPU في الـ benchmark. |
| البوت وقف لوحده | شوف السجل (آخر سطر "stop: ..."). |
| اتصاب HUD بعدم ظهور | صلاحية الظهور فوق التطبيقات. |

## حدود معروفة
- تسجيل الشاشة بيطلب موافقة في كل تشغيل.
- لو اللعبة بتمنع التقاط الشاشة (FLAG_SECURE) الصورة هتبقى سودا.
- Accessibility backend أبطأ وأقل دقة من Shizuku.
- مفيش تعلّم بالتقليد جوّه التطبيق بعد (متروك لخطوة جاية).

## تراخيص
Shizuku و TensorFlow Lite: Apache-2.0. **Ultralytics YOLO: AGPL-3.0** — مناسب للاستخدام الشخصي والبحثي؛ لو هتوزّع منتج مغلق المصدر محتاج ترخيص Enterprise أو استخدم بديل (YOLOX / NanoDet / RT-DETR بترخيص Apache).
